# Completed rollbacks

Reversals planned by `/rollback` are archived here as `YYYY-MM-DD-NN-name.md`
when `/complete` closes them out.

A rollback never erases the original feature archive in `../features/`. Both stay
on the record: the feature was built, and then it was withdrawn. The source spec
goes back to `Ready`, because the contract still stands even though the
implementation was removed.

_Empty until you roll something back._
